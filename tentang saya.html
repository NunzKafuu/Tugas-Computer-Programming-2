Profil Mahasiswa Institut Teknologi Bisnis Riau

Tentang Feblianto Jakas Putra

Mahasiswa Bisnis Digital yang suka mengubah data menjadi uang.

Tentang Saya

Saya merupakan anak terakhir dari 4 bersaudara. Saya lahir di Pekanbaru pada tanggal 22 Februari 2007. Saat ini saya berusia 19 tahun dan sedang menempuh pendidikan di Institut Teknologi Bisnis Riau, Program Studi S1 Bisnis Digital, Semester 3. Alasan saya memilih program studi ini adalah karena saya menyukai uang dan teknologi, sehingga saya ingin mempelajari bagaimana cara mengubah data menjadi uang. Saya juga memiliki hobi bermain game dan menonton film. Saya berharap dengan belajar di program studi ini, saya dapat mengembangkan kemampuan saya dalam bidang bisnis digital dan dapat berkontribusi dalam dunia bisnis di masa depan.
